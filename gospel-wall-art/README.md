# Gospel Wall Art — TV wall set

11 orange-led gospel posters in mixed sizes, made for a salon-style wall around a TV.

| # | Poster | Print size |
|---|---|---|
| 01 | He Is Worthy (Rev 4:11) | 24×36 in |
| 02 | Hallelujah, I Am Not Alone (Deut 31:6) | 18×24 in |
| 03 | He Is My Shepherd (Psalm 23:1) | 18×24 in |
| 04 | Pray (1 Thess 5:17) | 12×16 in |
| 05 | Amen (Rev 22:20) | 16×20 in |
| 06 | Psalm Ninety One | 12×16 in |
| 07 | Grace Upon Grace (John 1:16) | 11×14 in |
| 08 | New Every Morning (Lam 3:22–23) — landscape | 20×16 in |
| 09 | Consider the Lilies (Matt 6:28) | 8×10 in |
| 10 | Romans 8:28 | 11×14 in |
| 11 | Be Still (Psalm 46:10) | 8×10 in |

- `print-pdf/` — vector PDFs at exact print size (sharp at any size, send straight to a print shop).
- `preview/` — PNG previews.
- `tv-wall-mockup.png` — suggested layout around a 65" TV.
- `build/` — source. `npm i` then `node render.mjs` to regenerate (needs Playwright).
